# My Nukkit-MOT Plugins

Здесь собраны мои авторские плагины для сервера Minecraft на базе Nukkit-MOT. 
Написаны на **Java** с использованием **Maven**.

---

## 🇷🇺 Описание (Russian)
* **EconomyExt** — расширенная экономическая система (исходный код в папке `My_Nukkit_Plugins/EconomyExt_Source`).
* **CreateAdmin** — инструмент для создания и управления администраторами.
* **PowerfulAdmin** — расширенные права и команды для администрации.
* **SWorldEdit** — утилита для работы с миром.

**Как установить:**
1. Скачайте `.jar` файл из папки `My_Nukkit_Plugins`.
2. Поместите его в папку `plugins` вашего сервера.
3. Перезапустите сервер.

---

## 🇬🇧 Description (English)
These are my custom plugins for a Minecraft server based on Nukkit-MOT. 
Written in **Java** using **Maven**.

* **EconomyExt** — Advanced economy system (source code is in the `My_Nukkit_Plugins/EconomyExt_Source` folder).
* **CreateAdmin** — Tool for creating and managing administrators.
* **PowerfulAdmin** — Extended permissions and commands for server administration.
* **SWorldEdit** — World manipulation utility.

**Installation:**
1. Download the `.jar` file from the `My_Nukkit_Plugins` folder.
2. Place it in the `plugins` folder of your Nukkit-MOT server.
3. Restart the server.
